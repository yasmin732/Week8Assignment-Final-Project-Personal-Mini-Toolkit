# Personal Mini-Toolkit

## What This Toolkit Does

The Personal Mini-Toolkit is a Python program that provides three simple tools in one menu. It includes a Simple Calculator, a To-Do List, and a Number Guessing Game. The calculator performs basic arithmetic operations. The To-Do List allows users to add, view, and remove tasks while the program is running. The Number Guessing Game allows users to guess a secret number and provides feedback until they guess correctly.

## How to Run

1. Open the project folder in a terminal.
2. Run the program using:

```bash
python toolkit.py
```

Choose a tool by entering a number from 1 to 4.
Choose option 4 to quit the program.

## Reflection

The hardest part of this project was making sure the menu and different tools worked correctly together. I also had to pay attention to indentation because Python uses indentation to organize code. Testing the To-Do List helped me understand how lists can change while a program is running. The Number Guessing Game helped me understand how loops and conditionals can work together. One bug I had to deal with was making sure the program returned to the main menu correctly after using a tool. I learned that testing each option separately makes it easier to find and fix problems. If I had another week, I would add more useful tools and improve the design of the toolkit.
